# UI Design Capsee

Kumpulan desain antarmuka aplikasi Capsee.

## Link Figma

[![Buka di Figma](https://img.shields.io/badge/Figma-Design-blue)](https://www.figma.com/design/l8uP3WlKO9h2eBlMCQ3nN0/PBL---Capsee?node-id=0-1&t=4mYiw0519STWqdEU-1)

## Cara Menambahkan Gambar

1. Ekspor setiap layar dari Figma sebagai PNG (lebar disarankan 360 px atau 1080 px).
2. Simpan berkas di folder `design/ui/` dengan nama sesuai daftar di bawah.
3. Gambar akan otomatis tampil pada README ini.
